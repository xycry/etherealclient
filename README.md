# ✦ Ethereal Client


### Minecraft, Reimagined.

**A fresh take on Minecraft 1.21.1.** Built on the foundation of Anubis, redesigned with a brand-new GUI, custom features, and a unique identity.

---

##  About

Welcome to **Ethereal Client** — a Minecraft client designed to bring a fresh experience to the game.

Taking inspiration from the open-source **Anubis** project, Ethereal introduces a completely redesigned interface, additional features, and custom improvements that make it its own.

Our goal is to combine a sleek aesthetic with useful functionality and create something that stands out.

## Features

-  **New GUI** — A completely redesigned user interface.
-  **Custom Features** — Additional functionality beyond the original Anubis foundation.
-  **Unique Design** — A sleek, modern visual identity.
-  **Custom Improvements** — Modifications and enhancements made for Ethereal.
-  **Future Updates** — More features and improvements planned.
